# 🌞 Surya-Glow

> A personalized skincare recommendation web app that helps you discover the right routine for your skin.

**Surya-Glow** ("Surya" meaning *sun* in Sanskrit) is a lightweight, browser-based skincare advisor. Tell it about your skin, and it returns recommendations tailored to your needs — no signup, no tracking, just clean advice.

## 🔗 Live Demo

👉 [Visit Surya-Glow](https://surya-glow.vercel.app/)

## ✨ Features

- 🧴 **Personalized Recommendations** — Get product and routine suggestions matched to your skin type

- 🔍 **Skin Concern Matching** — Targeted advice for acne, dryness, pigmentation, aging, and more

- 🌗 **AM / PM Routine Builder** — Separate guidance for morning and night skincare

- ☀️ **Sun Protection Focus** — Built-in SPF and sun-care recommendations

- 📱 **Fully Responsive** — Works seamlessly on mobile, tablet, and desktop

- ⚡ **Fast & Lightweight** — Pure HTML/CSS/JS, no heavy frameworks

- 🎨 **Clean, Minimal UI** — Easy to use, no clutter

## 🛠️ Tech Stack

- **HTML5**

- **CSS3**

- **JavaScript (Vanilla)**

## 🚀 Getting Started

To run Surya-Glow locally:

```bash

# Clone the repository

git clone https://github.com/Sagar-colab/Surya-Glow.git

# Navigate into the folder

cd Surya-Glow

# Open in your browser

open index.html

```

That's it — no build step, no dependencies.
